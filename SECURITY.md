# Política de segurança (protótipo)

O FiscalIA PFG v0.7.2 é experimental e não foi homologado para implantação institucional.

- Não envie a este repositório dados pessoais, contracheques, contratos reais, banco SQLite, arquivos de evidência ou chaves.
- Não exponha o servidor local (`127.0.0.1`) à internet.
- Faça testes com dados fictícios e mantenha backups fora do repositório.
- Consulte `SEGURANCA_PENDENCIAS.md` antes de qualquer implantação.

Em caso de descoberta de uma vulnerabilidade, evite divulgar detalhes exploráveis em *issues* públicos; use comunicação privada com o responsável pelo repositório ou a função de comunicação privada de vulnerabilidades do GitHub, se habilitada.
